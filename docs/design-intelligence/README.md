# NEXORA QR — Design Intelligence

This directory contains repository-safe design and product-engineering guidance for autonomous implementation.

## Source policy

Do not copy private company strategy, customer lists, credentials, acquisition data, or proprietary business playbooks into this public repository.

Private references may be supplied to the executor at runtime through the approved agent environment.

## Design priorities

1. Mobile-first
2. Arabic RTL first-class support
3. Fast comprehension and low interaction cost
4. Premium visual quality without sacrificing usability
5. Consistent design tokens and reusable components
6. Template-driven presentation with business logic kept outside templates
7. Accessibility and responsive behavior
8. Performance on real mobile networks
9. Production-safe empty/loading/error states
10. Visual verification for customer-facing flows

## Product rule

Design is a product capability in NEXORA QR. Templates should provide distinct visual identities while consuming the same stable menu domain contracts.

## Autonomous rule

When a design idea is outside the current execution step, record it in `.nexora/IDEAS.md` instead of silently expanding scope.
